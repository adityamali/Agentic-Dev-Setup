# Debugging history

Symptom → hypothesis → verification → root cause → fix → prevention.

## What belongs here

- Bugs whose pattern is worth preserving.
- Investigations that crossed multiple systems.
- Non-obvious root causes.

## What does NOT belong here

- Trivial bugs with no reusable lesson → handle in the project issue tracker.
- A bug that is still open → use [`../../templates/bug-report.md`](../../templates/bug-report.md) in the project first.
- General lessons → promote to `../lessons/`
