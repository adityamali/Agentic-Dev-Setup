# Memory Index

Map of Content (MOC) for the `memories/` knowledge base. Maintained by agents as notes are created, archived, or merged.

## How to maintain this file

- Add new notes under the appropriate section with a `[[wikilink]]`.
- Add new tags to the tag index when first used.
- Move notes to `archive/` in the filesystem and remove their active link here when they become obsolete.
- Merge duplicate notes by consolidating into one file and redirecting the other to it.
