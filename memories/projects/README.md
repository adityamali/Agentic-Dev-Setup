# Project notes

One note per project. This is the running knowledge about a project, not its formal architecture (which lives in `../../architecture/<slug>/`).

## What belongs here

- Current state, constraints, quirks, and stable observations about a project.
- Links to the project's ADRs and architecture docs.
- Cross-cutting facts that don't fit a single architecture section.

## What does NOT belong here

- Formal component/data-flow docs → `../../architecture/<slug>/`
- How-to guides for a technology → `../../technologies/`
- Decisions with trade-offs → `../../adr/`
- A debugging story → `../debugging/`

## Naming

`<slug>.md`, where `<slug>` matches the project folder under `../../architecture/`.

## Template

Use [`../../templates/memory-project.md`](../../templates/memory-project.md).
