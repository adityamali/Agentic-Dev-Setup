# Permanent notes

Evergreen engineering knowledge: principles, patterns, definitions, and mental models that stay true across projects.

## What belongs here

- Core concepts the team/agent repeatedly needs.
- Stable patterns with clear when-to-use / when-not-to-use guidance.
- Definitions that prevent terminology drift.

## What does NOT belong here

- Project-specific facts → `../projects/`
- A single tool's CLI flags → `../technologies/`
- A one-off debugging story → `../debugging/`
- A raw research dump → `../research/`
