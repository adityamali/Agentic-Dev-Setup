# Archive

Cold storage for obsolete or superseded memory notes.

## What belongs here

- Notes that are factually outdated and no longer referenced.
- Research notes whose findings were promoted.
- Superseded knowledge (with a note pointing to the replacement).

## What does NOT belong here

- Active knowledge. If it's still true and useful, it belongs in one of the other folders.
- Deleted-by-accident files. Archive deliberately.

## Procedure

1. Move the file from its current folder to `archive/`.
2. Set `status: archived` in frontmatter.
3. Update `updated`.
4. Remove its active link from `../INDEX.md`.
